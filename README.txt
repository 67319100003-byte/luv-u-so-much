ไฟล์เว็บไซต์บอกรักแฟน 💗

เริ่มใช้งาน:
1) แตกไฟล์ ZIP
2) เปิดโฟลเดอร์ love_website
3) ใส่รูปคู่ 3 รูปในโฟลเดอร์ assets โดยตั้งชื่อ:
   photo1.jpg
   photo2.jpg
   photo3.jpg
4) ใส่ไฟล์เพลงที่มีสิทธิ์ใช้งาน/ไฟล์ส่วนตัว ชื่อ love-song.mp3 ใน assets
5) เปิด index.html ในเบราว์เซอร์เพื่อทดลอง

ตั้งวันเริ่มคบกัน:
เปิด index.html แล้วค้นหา:
const relationshipStart = new Date("2024-02-14T00:00:00");
แก้วันที่เป็นวันเริ่มคบกันจริง เช่น 2023-12-25T00:00:00

ข้อควรรู้:
- เว็บใช้ Google Fonts จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์
- เบราว์เซอร์ส่วนใหญ่บล็อกเสียง autoplay จนกว่าผู้ใช้จะแตะปุ่มเล่นเพลง
- ก่อนเผยแพร่ ให้ใส่รูปและเพลงให้ครบ แล้วทดสอบบนมือถือ

เผยแพร่ด้วย GitHub Pages:
1) สมัคร/เข้าสู่ระบบ github.com
2) สร้าง repository ใหม่ ตั้งชื่อเช่น my-love
3) อัปโหลด index.html และโฟลเดอร์ assets ทั้งโฟลเดอร์
4) เข้า Settings > Pages
5) ใน Build and deployment เลือก Deploy from a branch
6) เลือก branch main และ folder /(root) แล้วกด Save
7) รอ GitHub แสดง URL เว็บไซต์ จากนั้นเปิด URL ทดสอบ

สร้าง QR Code:
1) คัดลอก URL เว็บไซต์ที่ GitHub Pages ให้มา
2) เปิดเว็บสร้าง QR Code ที่เชื่อถือได้ เช่น https://www.qrcode-monkey.com/
3) วาง URL แล้วสร้างและดาวน์โหลด QR Code
4) ลองสแกนด้วยมือถืออีกเครื่องก่อนส่งให้แฟน

หมายเหตุความเป็นส่วนตัว:
เว็บไซต์ที่เผยแพร่แบบ public อาจเปิดดูได้โดยทุกคนที่มีลิงก์หรือค้นพบ URL
อย่าใส่ข้อมูลส่วนตัวที่ไม่ต้องการเผยแพร่
